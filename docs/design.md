# 디자인 기준

넷플릭스 학습 패널(`src/pages/Content/*.css`)의 지금 모양에서 뽑은 기준이다(2026-11-07, 명세서 `docs/specs/20261107-2252-book-reader`의 결정). 확장 프로그램의 새 화면(원서 리더, 모아 보기, 팝업)은 이 기준으로 만든다. 학습 패널 자체는 이 문서 때문에 바꾸지 않는다.

## 1. 성격

- 공부 도구다. 꾸밈보다 글이 잘 읽히는 것이 먼저다.
- 따뜻한 종이색 바탕 위에 흰 카드와 회색 테두리 버튼을 쓴다. 강조색은 넷플릭스 빨강(현재 위치·주요 행동)과 초록(켜짐·완료) 둘뿐이다.
- 하이라이트는 노란 형광펜, 메모는 주황 계열로 한다. 이 둘은 학습 패널과 새 화면에서 똑같아야 한다.

## 3. 글꼴과 크기

- 글꼴: 시스템 기본 산세리프를 그대로 쓴다(학습 패널은 넷플릭스 글꼴을 물려받는다). 새 화면은 `system-ui, -apple-system, 'Segoe UI', 'Helvetica Neue', Arial, sans-serif`. 외부 글꼴을 불러오지 않는다.
- 본문(읽는 글): 기본 14pt, 사용자가 조절(학습 패널 `--base-font-size`). 보조 글(번역 등)은 본문의 0.9배, 기울임.
- 원서 리더 본문은 같은 크기 규칙을 쓰되, 긴 글이므로 줄 간격 1.6~1.8, 한 줄 최대 폭 70자 안팎으로 둔다.
- 버튼·도구 글: 13px(작은 버튼), 11pt(토글 버튼). 안내 글: 12px.
- 줄 간격: 메모 입력칸 1.5.

## 4. 간격·모서리·그림자

- 간격 단위: 4, 6, 8, 10, 12, 15, 16px. 버튼 안쪽 `6px 12px`(작음) / `8px 16px`(보통). 묶음 사이 `gap` 6~10px. 문장 카드 안쪽 15px.
- 모서리: 버튼·입력칸 4px, 떠 있는 작은 것(도구막대, 입력칸) 6px, 카드·영역·팝오버 8px.
- 그림자: 떠 있는 메뉴만 쓴다. 도구막대 `0 4px 12px rgba(0,0,0,0.25)`, 팝오버 `0 10px 25px -5px rgba(0,0,0,0.5)`. 카드에는 그림자를 쓰지 않는다.
- 움직임: `transition: all 0.2s ease`. 팝오버는 0.2초 아래에서 떠오른다.

## 5. 컴포넌트

- **기본 버튼**: 표면-옅음 바탕, 테두리, 글 `#333`, 4px 모서리, hover 표면-눌림. 켜진 상태는 초록 바탕 흰 글.
- **주요 버튼**: 빨강 바탕 흰 글(현재 페이지 버튼과 같음).
- **위험 버튼**: 흰 바탕, 위험 글·테두리.
- **페이지·목록 선택**: 숫자 버튼 줄. 현재는 빨강, 완료는 초록.
- **문장·문단 카드**: 8px 모서리, 안쪽 15px, 현재 위치면 현재 문장 바탕.
- **하이라이트**: `mark` 요소, 하이라이트 바탕, 2px 모서리. 메모가 있으면 2px 메모색 밑줄과 작은 `✎` 표시.
- **하이라이트 도구막대**: 어두운 표면, 6px 모서리, 흰 글 버튼 13px, 그림자. 고른 글 바로 위(공간이 없으면 아래).
- **메모 영역**: 메모 바탕·테두리, 8px 모서리, 안쪽 12px. 위에 고른 글 인용(왼쪽 3px 메모색 선, 굵게), 가운데 입력칸(최소 9em, 6줄 이상, 세로 크기 조절, 글이 늘면 자동으로 늘어남, 포커스 시 메모색 테두리와 옅은 테두리 빛), 아래 "자동 저장 · Esc로 닫기" 안내와 지우기·닫기 버튼.
- **떠 있는 메뉴(팝오버)**: 어두운 표면, 8px 모서리, 안쪽 16px, 팝오버 그림자.
- **입력칸**: 흰 바탕, 테두리, 4~6px 모서리, 포커스 시 테두리 색을 진하게.
- **학습 진행률 막대**: 높이 8px, 끝이 둥근(999px) 표면-옅음 바탕에 테두리, 채운 부분은 켜짐(초록). 막대는 꾸밈이고 옆에 "45% · 12장 중 5장 완료" 문구(13px)를 함께 쓴다. 책 목록은 막대 폭 최대 240px, 리더 장 목록 위에서는 폭 전체.
- **장 목록의 학습 완료**: 장 버튼 오른쪽에 24px 체크 상자(진한 초록 `accent-color`). 완료한 장은 번호 대신 진한 초록 `✓`.
- **켜진 버튼(글이 있는 초록)**: 흰 글이 올라가는 켜진 상태는 대비 4.5:1을 넘도록 진한 초록 `#047857`(hover `#059669`)을 쓴다. 글이 없는 표시(막대, 체크)는 켜짐 초록 `#10b981`.
- **완료 안내**: 옅은 초록 바탕 `#ecfdf5`, 켜짐 초록 테두리, 진한 초록 굵은 글 13px, 4px 모서리.
- **읽기 도구(소리 내어 읽기)**: 본문 위, 머리글 바로 아래에 붙어 있는(sticky) 흰 띠. 아래 테두리로 본문과 나눈다. 줄마다 기본 버튼을 6px 간격으로 놓고, 재생/일시정지는 주요 버튼, 문장 반복·문장마다 멈춤은 켜지면 켜진 버튼(`aria-pressed`). 속도·음성은 기본 `select`와 13px 이름표.
- **음성 안내**: 좋은 음성이 없어 기본 음성을 보일 때 읽기 띠 아래에 13px 보조 글로 알린다.
- **현재 문장**: 읽는 문장에 현재 문장 바탕(2px 모서리). 하이라이트 안에서는 아래쪽 40% 띠로만 그려 하이라이트 색을 가리지 않는다.
- **여기서부터 읽기**: 문단 왼쪽 바깥 24px 원형 ▶ 버튼. 문단에 마우스를 올리거나 포커스하면 보인다.

### 계정과 저장 안내(명세서 `docs/specs/20261108-0925-firebase-sync`)

- **로그인 화면**: 바탕 가운데 최대 폭 480px 흰 카드(테두리, 8px 모서리, 안쪽 24px). 제목 22px, 설명(줄 간격 1.6), 주요 버튼 "Google로 로그인"(안쪽 `8px 16px`, 15px), 그 아래 12px 보조 글로 방침 링크. 상태마다 같은 카드를 쓴다: 확인 중(대기 표시만), 설정 없음(버튼 없이 안내), 로그아웃·만료·취소·탈퇴 뒤(제목 위에 표면-옅음 바탕의 13px 안내 상자).
- **대기 표시**: 16px 원형 회전 표시(테두리색 고리, 위쪽만 빨강)와 보조 글. `prefers-reduced-motion`이면 돌지 않는다. 로그인 버튼은 누른 동안 비활성과 "로그인하는 중입니다…"로 바꾼다.
- **계정 표시**: 머리글 오른쪽, 백업 버튼 다음에 13px 한 줄로 이메일(넘치면 말줄임), 보조 글 "사용량 n.n MB / 20 MB", 기본 버튼 "로그아웃", 위험 버튼 "탈퇴". 상한에 닿으면 사용량 글을 위험 글 굵게 하고 "· 가득 참"을 붙인다.
- **확인 대화상자**: 기본 `dialog` 요소를 `showModal`로 띄운다(포커스 가두기·Esc 닫기를 브라우저가 맡는다). 폭 최대 480px 흰 카드, 8px 모서리, 안쪽 24px, 뒤 막 `rgba(0,0,0,0.4)`. 제목 18px, 본문 14px(줄 간격 1.6), 오른쪽 아래에 "취소"(기본 버튼)와 실행 버튼. 되돌릴 수 없는 실행(탈퇴)은 위험 버튼이고, 무엇이 지워지는지와 백업 내보내기 버튼, 방침 링크를 본문에 둔다. 실패는 대화상자 안의 위험 색 상자로 알린다.
- **저장 오류 안내**: 머리글 아래 띠. 위험 색(바탕·테두리·글), 8px 모서리, 13px, `role="alert"`. 다시 시도할 수 있는 오류(네트워크, 무료 한도, 알 수 없는 오류)에만 "다시 시도" 버튼을 두고, 모든 안내에 닫기 버튼을 둔다. 원래 오류 문구는 보이지 않고 종류별 정해 둔 문구만 쓴다.
- **넷플릭스 패널의 안내**: 저장이 필요한 자리(메모, 체크리스트, 공부한 영상 목록, 대시보드)에 13px 안내 상자(8px 모서리, 안쪽 `10px 12px`). 밝은 자리는 표면·테두리, 어두운 자리(대시보드)는 어두운 표면. 로그인 안내에는 확장 프로그램 화면을 여는 "로그인 화면 열기" 주요 버튼을 둔다(넷플릭스 화면에서 직접 로그인하지 않는다). 대기는 보조 글, 오류는 위험 색.

### 원서 고치기(명세서 `docs/specs/20261111-1712-book-edit`)

- **책 편집의 장 목록**: 장마다 카드 한 줄(8px 간격, 안쪽 `10px 12px`, 줄 안 간격 10px, 좁으면 줄바꿈). 왼쪽부터 13px 보조 글 번호(최소 폭 24px, 오른쪽 맞춤), 남는 폭을 채우는 제목 입력칸, 13px 보조 글 "문단 n개", 6px 간격의 버튼 묶음. 순서 버튼 ↑·↓는 최소 폭 36px 기본 버튼이고 `aria-label`로 장 이름과 방향을 알린다. 그 옆에 기본 버튼 "본문 고치기"와 위험 버튼 "지우기". 제목 입력칸은 입력을 마칠 때 저장하고, 잘못된 값은 입력칸 아래 위험 글로 알린다. 목록 위 소제목은 16px, 도움말은 13px 보조 글(줄 간격 1.5).
- **장 추가**: "장 추가" 기본 버튼을 누르면 그 자리에 흰 카드(안쪽 16px, 항목 간격 12px)가 열린다. 제목 입력칸, 등록 화면과 같은 본문 입력칸, 아래 줄에 "본문 정리" 체크와 오른쪽 "취소"(기본 버튼)·"장 저장"(주요 버튼).
- **편집 안내 상자**(`.nfr-edit-notice`): 다른 곳에서 책이 바뀌어 다시 읽었을 때처럼 오류가 아닌 알림. 표면-옅음 바탕, 테두리, 4px 모서리, 안쪽 `8px 12px`, 13px, `role="status"`. 리더에서 보던 장이 지워졌을 때도 쓴다.
- **본문 편집 입력칸**: 화면 최대 폭 1100px. 기본 `textarea` 하나에 장 전체를 넣는다. 14px, 줄 간격 1.6, 높이 `calc(100vh - 380px)`(최소 280px), 세로 크기 조절. 입력칸 모양은 기준의 입력칸과 같다.
- **찾아 바꾸기 줄**: 입력칸 위의 흰 띠(테두리, 8px 모서리, 안쪽 `10px 12px`, 간격 8px, 좁으면 줄바꿈). 13px 굵은 이름표가 위에 붙은 "찾을 글"·"바꿀 글" 입력칸, "대소문자 구분" 체크, 기본 버튼 "다음 찾기"·"바꾸기"·"모두 바꾸기", 끝에 13px 보조 글로 찾은 개수나 결과(`role="status"`, 최소 폭 90px로 자리를 잡아 둔다).
- **변경 요약과 아래 실행 줄**: 입력칸 아래 한 줄(간격 10px). 왼쪽에 13px 버튼 글 색의 변경 요약 "문단 120→118 · 글자 −340"(`aria-live="polite"`), 0.3초 넘게 걸릴 때만 대기 표시, 오른쪽에 "취소"(기본 버튼)와 "저장"(주요 버튼).
- **편집 창 안의 오류**: 입력칸과 실행 줄 사이에 위험 색 상자(바탕·테두리·글, 4px 모서리, 안쪽 `8px 12px`, `role="alert"`). 동시 수정 안내는 같은 상자 안에 기본 버튼 "새 본문으로 다시 열기"를 둔다. 저장 오류의 종류별 안내는 머리글 아래 저장 오류 안내가 맡는다.
- **확인**: 원서 고치기의 확인(장 지우기, 붙일 수 없는 메모·글이 크게 줄 때의 저장, 저장하지 않고 나가기, 새 본문으로 다시 열기)은 모두 위의 확인 대화상자를 쓴다. 그만두는 쪽("취소", "계속 고치기")이 기본 버튼이고 처음 포커스를 받으며, 지우거나 버리는 실행("지우기", "메모 남기기", "메모도 지우기", "그래도 저장", "저장하지 않고 나가기", "다시 열기")은 위험 버튼이다.
- **붙일 수 없는 메모 목록**: 확인 대화상자 본문 안의 목록. 항목마다 왼쪽 3px 메모색 선, 메모 영역 바탕, 안쪽 `6px 10px`, 13px(줄 간격 1.5), 고른 글은 굵게, 메모 글 앞부분은 보조 글. 항목 간격 6px, 최대 높이 40vh를 넘으면 목록 안에서 스크롤하고, 키보드로 스크롤할 수 있게 포커스를 받는다(포커스 시 2px 빨강 외곽선).

## 6. 문구

- 한국어 존댓말(~합니다/~하세요). 버튼은 짧은 명사·동사("하이라이트", "메모", "닫기", "하이라이트 지우기").
- 되돌릴 수 없는 일은 무엇이 얼마나 지워지는지 적어 묻는다. 계정 관련 확인(로그아웃, 탈퇴)과 원서 고치기의 확인은 5장의 확인 대화상자로 묻는다. 그 밖의 기존 확인(책 목록의 책 지우기, 메모가 있는 하이라이트 지우기, 백업 가져오기)은 `window.confirm`으로 묻는다.

## 7. 접근성

- 버튼은 `button` 요소로 만들고, 아이콘만 있는 버튼에는 `aria-label`이나 `title`을 둔다.
- 입력칸에는 이름(`aria-label` 또는 `label`)을 둔다.
- 키보드로 주요 흐름을 할 수 있어야 하고, 포커스가 보여야 한다.
- 글과 바탕의 대비는 WCAG AA(본문 4.5:1)를 지킨다. 보조 글 `#666`은 흰 바탕·종이색 바탕 모두에서 AA를 넘는다.
