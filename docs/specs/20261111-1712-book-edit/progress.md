## 재량 결정

- 새 장 id는 `c-` + `createId()`(시각+난수)로 만든다. 쓴 적 있는 id를 기억할 필요가 없고 책 정보에 항목을 더하지 않는다.
- 화면은 주소가 따로 있는 두 화면으로 둔다: 책 편집 `#/book/<id>/edit`, 장 본문 편집 `#/book/<id>/edit/<장 id>`. 뒤로 가기와 나가기 확인을 주소 변화 한 곳에서 다룬다.
- 본문 비교는 문단 단위로 먼저 맞추고, 바뀐 구간만 낱말 단위로 비교한다(`fast-diff`). 큰 장에서 오타 몇 개를 고칠 때 빠르고, 고친 곳이 낱말 경계에 맞아 "teh→the"가 한 덩어리로 잡힌다.
- 위치를 옮긴 메모는 `updatedAt`을 저장 시각으로 올린다. 고친 뒤 받은 백업을 옛 상태에 가져올 때 파일 쪽 메모가 이기게 하기 위해서다(4.7-2).
